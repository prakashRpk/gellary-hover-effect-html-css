# Gallery Hover Effect 🎨🖼️

A modern and responsive **image gallery** with elegant **hover effects**, created using **HTML** and **CSS**. Ideal for portfolio sections, photography showcases, or landing pages.

## 🔗 Live Demo

[View Live](https://prakashrpk.github.io/gellary-hover-effect-html-css/)  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (hover transitions and effects)

---

## ✨ Features

- Responsive image grid layout
- Smooth hover effect (zoom, overlay, or title reveal)
- Lightweight and easy to customize
- Clean, modern design
